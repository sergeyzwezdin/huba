Huba is fully keyboard-driven. Press `?` at any time to open the help dialog with a quick reference.

## Navigation

| Key | Action |
|-----|--------|
| `q` | Exit application |
| `s` | Open settings |
| `Shift+L` | Open task list selector |
| `Shift+M` | Switch to the most recently created list |
| `1` | Focus task list panel |
| `2` | Focus task details panel |
| `3` | Focus "blocked by" panel |
| `4` | Focus "blocks" panel |
| `Escape` | Go back / unfocus current panel |
| `Enter` | Open task details full page / confirm selection |

## View

| Key | Action |
|-----|--------|
| `/` or `Space` | Toggle task details panel |
| `h` | Toggle horizontal / vertical layout |
| `p` | Toggle progress bar |
| `w` | Cycle theme forward |
| `Shift+W` | Cycle theme backward |
| `?` | Open help dialog |

## Search

| Key | Action |
|-----|--------|
| `:` | Focus search input |
| `Escape` | Clear search text, or exit search if already empty |
| `Enter` | Confirm search and return focus to task table |

## Filter

| Key | Action |
|-----|--------|
| `Shift+F` | Cycle status filter: All → Pending → In Progress → Completed |

## Sort

| Key | Action |
|-----|--------|
| `Shift+I` | Sort by task ID |
| `Shift+T` | Sort by title |
| `Shift+S` | Sort by status |
| `Shift+D` | Sort by date |

Pressing the same sort key again toggles between ascending and descending order.

## Scrolling

| Key | Action |
|-----|--------|
| `Up` or `k` | Scroll up |
| `Down` or `j` | Scroll down |

These keys work in scrollable panels like task details, blocked by, and blocks.
