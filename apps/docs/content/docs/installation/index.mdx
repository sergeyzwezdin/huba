Huba is distributed as a standalone CLI tool that runs in your terminal. It requires [Claude Code](https://code.claude.com/docs/en/overview) to be installed on your system, as Huba reads and manages task lists created by Claude Code.

Depending on your platform, you can install Huba via **Homebrew** (macOS and Linux) or **npm** (all platforms). Choose the guide for your operating system below:

- **[macOS](/docs/installation/macos)** — install via Homebrew or npm
- **[Linux](/docs/installation/linux)** — install via Homebrew or npm
- **[Windows](/docs/installation/windows)** — install via npm

Each guide covers installation, running the app, upgrading to the latest version, and uninstalling.
